# Цели на семестр

1. Освоить основы машинного обучения. Разобраться с линейной и логистической регрессией, деревьями решений и тем, как делить данные на обучающую и тестовую выборки. К концу семестра обучить хотя бы одну модель на scikit-learn на своём датасете.
2. Научиться упаковывать свои проекты в Docker. Хочу, чтобы любой мой учебный проект запускался одной командой `docker compose up`, без ручной установки зависимостей.
3. Настроить GitHub Actions в этом репозитории, чтобы на каждый пуш сам запускался хотя бы один автоматический тест или проверка.
