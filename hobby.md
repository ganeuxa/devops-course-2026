# Мой пет-проект

Идея: сервис для репетиторов, где можно вести учеников и оплаты. На сайте репетитор заводит учеников, ставит занятия в расписание и отмечает, кто заплатил. Telegram-бот напоминает о занятии за час и раз в неделю присылает список тех, кто не оплатил прошлые уроки.

Стек: Python. Бот на aiogram, сайт на FastAPI, база PostgreSQL.

Цель: научиться собирать проект из нескольких сервисов (бот, сайт и база), запускать их одной командой через Docker Compose и выкладывать на сервер через GitHub Actions.

Сроки: MVP бота с напоминаниями к ноябрю, сайт к декабрю, Docker Compose и деплой через GitHub Actions к концу семестра.
