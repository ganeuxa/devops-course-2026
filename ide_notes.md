# VS Code и терминал

## Что удобнее в VS Code

1. Diff открывается в две колонки: слева старая версия файла, справа новая, изменённые строки подсвечены. git diff в терминале показывает то же самое, но одним списком с плюсами и минусами, и в длинном файле в нём легко потеряться.
2. Граф коммитов в Source Control. Сразу видно ветки и где они разошлись, не нужно набирать git log --oneline --all --graph.
3. GitLens при наведении на строку показывает, кто и когда её последний раз менял и в каком коммите. В терминале для этого нужен git blame, и вывод у него неудобно читать.

## Что удобнее в терминале

Создавать ветки, переключаться между ними и пушить новую ветку. git switch -c и git push origin <ветка> набираются быстрее, чем искать нужный пункт в меню. К тому же на сервере по SSH VS Code не будет, там только терминал.
